# 🧠 Learning Approach

For each major ML algorithm, I follow this cycle:

1. Understand the intuition
2. Understand the mathematics
3. Implement the algorithm from scratch
4. Implement it using Scikit-learn
5. Experiment with different parameters
6. Evaluate the model
7. Apply the concept to a mini-project
8. Prepare interview questions

The goal is not just to know how to call a library function, but to understand what is happening underneath it.
