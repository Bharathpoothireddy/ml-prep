# Day 2 — Matplotlib & Seaborn Revision

## Goal
Re-activate visualization fundamentals by producing five core plot types 
from scratch and extracting insight from each.

## Topics Covered
- Histogram (distribution)
- Box plot (spread + outliers)
- Bar chart (category comparison)
- Scatter plot (bivariate relationship)
- Heatmap (correlation)
- Pairplot (full pairwise view)
- Subplots (multi-plot storytelling)

## Key Takeaways
- Pick the plot based on the question, not habit
- Always label axes and add a title
- Seaborn for speed, Matplotlib for control
- A plot without an observation is just decoration
